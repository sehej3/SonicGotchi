#  SonicGochi

A virtual pet productivity timer that evolves based on your Spotify focus music.

Start a focus block, play your music, and your pet works alongside you. Its
appearance evolves with the genres you listen to, and skipping songs or pausing
mid-session hurts its health.

## Features
- **Focus timer:** 15, 25 or 50 minute Pomodoro blocks, with a Turbo mode for demos
- **Living pet:** animated SVG states for idle, working, distracted and hurt
- **Sonic DNA:** minutes focused are tracked per genre (Ambient, Electronic, Metal) and decide your pet's evolution
- **Design your own pet:** customize name, colors, eyes, mouth, ears and patterns
- **Sonic Coins and shop:** earn coins for finished blocks and buy cosmetics
- **Focus Wrapped:** a dashboard of your genre mix, top artists and session stats
- **Spotify integration:** real Spotify login (PKCE) with a built-in offline mock mode
- **Saved progress:** your pet, coins and design are stored in the browser

## Tech stack
React · Vite · Tailwind CSS · Zustand · Framer Motion · Lucide · Spotify Web API

## Getting started
    npm install
    npm run dev

Runs in mock mode by default. To use real Spotify, see the "Real Spotify"
section below.
